# Code of conduct

Be respectful, specific and constructive. Welcome contributors with different experience, backgrounds and perspectives. Critique ideas and implementations, not people. Harassment, threats, discriminatory language, doxxing, unwanted sexual attention and disclosure of private information are not acceptable.

Maintainers may edit or remove inappropriate content, pause a discussion, or restrict participation. Enforcement should be proportionate and explain the behavior at issue. Report concerns privately through a maintainer channel listed on the repository profile; do not post private details in public issues. If no private channel is listed, request one without disclosing sensitive information.

This policy applies to project issues, pull requests, discussions and other spaces where someone represents the project. Good-faith disagreement about technical decisions is welcome.
